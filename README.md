# nafis-privacy

Privacy policy for the **Nafis** app — https://vette1123.github.io/nafis-privacy/

Nafis (نفيس) is an offline-first, keyless local-price tracker for gold, silver,
platinum & crypto, with a portfolio, zakat, alerts, and per-country news.

The policy lives in [`index.html`](index.html) and is served via GitHub Pages.
This repo is intentionally separate from the app repo so the app repo runs no
Pages build. Update `index.html` here (and the "Last updated" date) when the
policy changes.
