# Description bound matches www: 160

## What

www's weekly `check:prod` (all 949 pages) failed twice on hadeed's `/projects/hadeed/go`:
description 163 chars, limit 160. This kit's `check-site.mjs` and `features.test.mjs` allowed
up to 170, so the source repo stayed green. Both bounds are 160 now, here and in hadeed-privacy.

## Mistakes

- The kit carried its own description bound instead of www's. Every copy of the kit inherited it,
  and the gap only showed on www's weekly run, which nobody was watching.

## What worked

- The full `check:prod --all` on www named the single page; the tightened kit check went red on
  that page before the copy was fixed.

## Rules

- A limit the www check enforces is the limit in every app kit. Change one, change all.
